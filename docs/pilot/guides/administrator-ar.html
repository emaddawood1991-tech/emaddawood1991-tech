دليل مسؤول النظام

مسؤولو النظام: الحسابات والإعدادات والأمان والنسخ الاحتياطي. صفة المسؤول لا تتيح علاج المرضى.

تسجيل الدخول. سجّل الدخول. التحقق بخطوتين إلزامي. احتفظ برموز الاسترداد العشرة في مكان آمن ومنفصل.
اسم المستخدم التجريبي: adminكلمة المرور (يعطيك إياها مسؤول التجربة):

يومك

  1. الإعدادات ← الموظفون: أضف كل شخص بقالب دور وقسم و(بشكل منفصل) الخدمات المصرّح بها. أعطه كلمة مرور مؤقتة؛ عليه تغييرها.
  2. الإعدادات ← الخدمات / الغرف / فئات المواعيد / رموز الإجراءات: طابقها مع العيادة. أضف رموز الإجراءات المعتمدة (لا يأتي النظام بأي رمز).
  3. الإعدادات ← الأمان والوصول ← الحسابات: إعادة ضبط كلمة المرور، إنهاء الجلسات، إعادة ضبط التحقق بخطوتين، تغيير اسم المستخدم.
  4. الاستعادة والطوارئ: أجب عن طلبات مساعدة الدخول (تحقق من هوية الشخص بنفسك أولًا). راجع كل استخدام للوصول الطارئ مع ملاحظة.
  5. التنبيهات: اقرأها وأقرّ بها. سجل التدقيق: رشّح السجل؛ «تحقق الآن» يفحص أنه لم يُعدَّل.
  6. السجلات المكررة: وافق على الروابط التي يقترحها المديرون؛ تراجع عنها بسبب إن كانت خاطئة.
  7. الجاهزية للتشغيل: يجب أن يكون كل بند سليمًا قبل البيانات الحقيقية. إعدادات الأمان: كلمات المرور ودقائق الخمول والحدود.
  8. النسخ الاحتياطي: npm run backup:run و backup:drill على الخادم؛ الاستعادة في ملف جديد فقط.
افعل
  • أنشئ الحسابات عبر قوالب الأدوار.
  • تحقق من الهوية قبل أي إعادة ضبط.
  • راجع استخدامات الوصول الطارئ خلال 24 ساعة.
  • عطّل حسابات من غادروا — لا تحذف أبدًا.
لا تفعل
  • لا تشارك حساب المسؤول.
  • لا تُوقف التحقق بخطوتين.
  • لا تستخدم النظام التجريبي لبيانات مرضى حقيقية.
إذا حدث خطأ
  • لا يستطيع أي مسؤول الدخول: على الخادم npm run mfa:reset -- <اسم المستخدم>.
  • بند فاشل في الجاهزية: افتح دليل التشغيل الفعلي، القسم 4.
مادة تدريبية — بيانات تجريبية فقط. لا تُدخل بيانات مرضى حقيقية في النظام التجريبي.لديك سؤال؟ اسأل مسؤول التجربة.
