What a server offers

Three primitives.

A server exposes tools, resources and prompts.

Who controls each one
Toolsmodel-controlled
Functions the LLM can call to take actions.
Resourcesapp-controlled
Context the client attaches, like file contents.
Promptsuser-controlled
Templates you pick, like slash commands.
Tools can take actions, so keep a human in the loop.

What changed

The handshake is gone.

Legacy
Revisions 2025-11-25 and earlier
An initialize handshake comes first
HTTP used Mcp-Session-Id sessions
Modern
Revisions 2026-07-28 and later
No handshake. Each request stands alone
Version and capabilities travel in _meta
Sametools/list and tools/call still apply.
Check which spec revision your tools speak.
