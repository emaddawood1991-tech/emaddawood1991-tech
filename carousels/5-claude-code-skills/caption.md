## Caption (copy-paste)

Stop retyping the same prompts. 🛑

Claude Code ships with built-in skills you can run with one slash command:

⚡ /simplify — clean up your changes before review
🔍 /code-review — review a diff, PR, branch or path
🧩 /batch — split a big change across parallel agents
🔁 /loop — run a prompt again on an interval
🐞 /debug — turn on debug logging and troubleshoot from the log

Quick notes: /simplify doesn't hunt bugs, /batch needs a git repo (or a WorktreeCreate hook), /loop only runs while your session is open, and /debug logs from the moment you run it.
