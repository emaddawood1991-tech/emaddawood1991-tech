## Caption (copy-paste)

Stop retyping the same prompts. 🛑

These 5 bundled skills ship with Claude Code. Each one is a single slash command:

⚡ /simplify — four agents tidy your changed code, then apply the cleanup
🔍 /code-review — review a branch, PR or path for bugs
🧩 /batch — split a big change into parallel agents (you approve the plan first)
🔁 /loop — re-run a prompt on an interval
🐞 /debug — turn on debug logging and troubleshoot from the log

Good to know:
• /simplify doesn't hunt bugs. That's /code-review.
• /code-review ultra is a cloud review and needs a claude.ai login.
• /batch needs a git repo (or a WorktreeCreate hook).
• /loop only runs while your session is open and ends after 7 days.
• /debug logs from the moment you run it, not before.
