The idea

Stop retyping the same prompts.

A skill is a saved playbook: type /name and Claude follows it.

Know the difference: four kinds of slash command
Built-in command/compact
Fixed logic in the CLI. Not a skill.
Bundled skill/simplify
Ships with Claude Code. All 5 in this post.
Custom skill/fix-issue
You write it in a SKILL.md file.
Plugin skill/plugin:skill
Comes from a plugin you install.
