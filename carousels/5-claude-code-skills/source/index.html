Skill 01 / 05
/simplify

Tidy your changes before anyone reviews them.

Reviews your changed code for cleanup opportunities, then applies the fixes.

> /simplify > /simplify src/api # aim at a path
Not a bug hunt/simplify does not look for correctness bugs. Use /code-review for that.

Skill 02 / 05
/code-review

A second pair of eyes, on demand.

Reviews your diff, a PR number, a branch, or a path for correctness bugs.

> /code-review high --fix > /code-review 1234 --comment
Tip/review is an alias. ultra runs a deeper review in the cloud.

Skill 03 / 05
/batch

One instruction. Many parallel agents.

Splits a large change into independent units and works on them in parallel.

> /batch migrate src/ from JavaScript to TypeScript
Needs gitNeeds a git repository (or a WorktreeCreate hook). Review the plan before approving.

Skill 04 / 05
/loop

Let Claude babysit it for you.

Runs a prompt again and again on an interval. Skip the interval and Claude paces itself.

> /loop 5m check if the deploy finished
Stays openIt runs only while your session stays open.

Skill 05 / 05
/debug

Ask Claude to read its own logs.

Turns on debug logging for this session, then troubleshoots from the log.

> /debug the build hangs after I save
TimingLogging is off by default. /debug captures from that moment forward, not before.
