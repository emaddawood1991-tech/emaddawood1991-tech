## Installers (no commands to run — download only)
Per each app's README "Downloads" section (file names use the version number in place of `<ver>`; `SHA256SUMS.txt` lists checksums; Windows installers/executables are code-signed, macOS builds signed and notarized):
- **Windows:** `<app>-<ver>-windows-x64.msi` (also `arm64`, `x86`) or `<app>-<ver>-windows-x64-portable.zip`
- **macOS:** `<app>-<ver>-macos-universal.dmg` (Apple silicon + Intel)
- **Linux:** `.AppImage`, `.flatpak`, `.deb`, `.rpm`, `.tar.gz` for x86_64 and aarch64 (riscv64 tarball)
- Also FreeBSD tarball and a web (WebAssembly) zip.

Launcher v0.7.0 assets read from the release page (exact names): `artcraft-launcher-0.7.0-windows-x64.msi` (+ x86, arm64, `-portable.zip`), `artcraft-launcher-0.7.0-macos-universal.dmg`, `artcraft-launcher-0.7.0-linux-x86_64.AppImage|.deb|.rpm|.flatpak|.tar.gz` (+ aarch64), `artcraft-launcher-web-0.7.0.zip`, `SHA256SUMS.txt`. Base URL: `https://github.com/storytold/craft-launcher/releases/download/v0.7.0/<file>`.
