## Caption (copy-paste)

Your Claude Code skills don't have to stay static. 🧠

task-observer watches your sessions and stages suggested skill updates. You review them before anything changes.

Four tools worth knowing:

🔭 task-observer: a meta-skill by Eoghan Henn that notes your corrections and skill gaps, then suggests improvements
🎨 impeccable: Paul Bakaus's design-guidance skill with commands like /impeccable audit and /impeccable polish
🧰 skill-creator: Anthropic's official plugin for building and testing skills
📚 anthropics/skills: Anthropic's example skills and the Agent Skills spec

Install (from each project's README and the Claude Code docs):
• npx skills add rebelytics/one-skill-to-rule-them-all --skill task-observer
• /plugin marketplace add pbakaus/impeccable
• /plugin install skill-creator@claude-plugins-official

Good to know:
• Personal skills live in ~/.claude/skills/<name>/SKILL.md (every project on your machine, not cloud sessions). Project skills live in .claude/skills/<name>/SKILL.md.
• task-observer needs its full folder, and the README recommends a CLAUDE.md instruction or session-start hook so it actually runs. It doesn't modify your installed skills. Nothing goes live until you install the updated bundle.
• Check a skill is really used: run /skills, call it directly, and look for its instructions in the transcript.
• Check each project's license (task-observer: CC BY 4.0, impeccable: Apache-2.0).
