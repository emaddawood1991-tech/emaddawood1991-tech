The basics

What are Claude Code skills?

A skill is a folder with a SKILL.md. Claude follows it for a specialized task.

# .claude/skills/fix-issue/SKILL.md --- name: fix-issue description: Fix a GitHub issue --- Fix GitHub issue $ARGUMENTS
Used whenYou type /fix-issue 123, or Claude loads it when your request matches.

More Skills, Better Workflows.

Official plugin that helps you build and test skills.
github.com/anthropics/claude-plugins-official

anthropics/skillsCollection
Anthropic’s example skills and the Agent Skills spec.
github.com/anthropics/skills
/plugin marketplace add anthropics/skills
Know the difference
SKILLa SKILL.md folder Claude follows
PLUGINa bundle you add with /plugin
CLIa standalone tool, like npx impeccable
MCP SERVERconnects outside tools. None here.

Install

Install Skills in Claude Code.

Personal
~/.claude/skills/<name>/SKILL.md
Every project on this machine
Project
.claude/skills/<name>/SKILL.md
This repo. Commit to share.
# task-observer (add -g for all projects) $ npx skills add rebelytics/one-skill-to-rule-them-all --skill task-observer # impeccable, inside Claude Code > /plugin marketplace add pbakaus/impeccable
ReloadMade a new top-level skills folder? Run /reload-skills.

Verify

Test Your Skills.

1
Is it recognized?
Ask “What skills are available?” or run:
/skills
2
Run it directly
A realistic example:
/impeccable polish settings
3
Did it really run?
The skill’s instructions enter the conversation when it is invoked. Look for them in the transcript.
4
Not triggering?
Check the description, try /name, or run with --debug to see frontmatter errors.
task-observerCheck skill-observations/checkpoints.log for a recent “session-start scan” line.
