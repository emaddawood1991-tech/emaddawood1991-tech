Configure the connection

Step 3 — Connect the API

$ kapso login $ kapso status $ kapso whatsapp messages send \ --phone-number-id <ID> --to <wa-id> \ --text "Hello from Kapso"
Credentials
Keep KAPSO_API_KEY in env vars. Never in code or chat.
Phone number ID
Find it with kapso whatsapp numbers list.
Webhook + signature
Receive whatsapp.message.received. Verify X-Webhook-Signature.
NeverNever post a real key. Test incoming and outgoing messages first.

Pricing + rules

Start Small. Scale Later.

Kapso subscription
Plans and message limits are on the official pricing page.
Meta WhatsApp fees
Meta bills messaging separately, by message type.
AI model usage
Your model provider bills the tokens your agent uses.
Hosting + integrations
Your server, calendar and database may cost extra.
WhatsApp rules
Replies need an active 24-hour customer-service window. Outside it, send an approved template.
PricingNot everything is free. Check the live Kapso pricing page.
