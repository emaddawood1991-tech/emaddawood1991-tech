# Run sheet · how to produce the 15 real edits (owner action, ~15 minutes once photos exist)
1. Open ChatGPT in your own signed-in account (https://chatgpt.com). Help: https://help.openai.com/en/articles/11084440-images-in-chatgpt
2. For each effect NN in `data/PROMPT-PACK.txt`: upload the matching source photo (`sources/NN.*`), paste the FULL prompt exactly, wait for the result.
3. Save the result as `results/NN.png` (for 04 /bgremove keep the transparent PNG). If a result is poor, rerun once and note it in the tracking sheet (Quality / Limitations); never retouch a result.
4. Screen-record ONE clean take of upload -> prompt -> result (portrait or zoomable 16:9) so the video can show the real ChatGPT interaction. Name it `results/ui-recording.mp4`.
5. Upload `sources/`, `results/` (and the recording) to the session. Claude rebuilds the preview, replacing every PENDING panel.
Nothing in this run sheet needs your password or key; never share them.
