# Selection matrix (signals -> skills)

| Signal in the brief / footage | Add | Why |
|---|---|---|
| Software, website, terminal, app, GitHub, settings screens | `agentoon-ui` | Real recordings/captures, cursor, smart zoom, verbatim code |
| Two or more systems connect (MCP, API, agent, webhook, pipeline) | `agentoon-diagrams` | Build the flow on the narration; label diagram vs proof |
| Before/after, restore, transformation, image edit, upgrade | `agentoon-morph` | Real before/after assets, comparison reveal |
| A place, product, object, building, hardware (TV, phone) shown as a subject | `agentoon-3d` | Blender/3D only when depth or form is the point |
| Orbit, fly-through, reveal of a large subject, product hero | `agentoon-camera` | Camera choreography |
| Many scenes of cards/lists/steps, UI chrome that must feel alive | `agentoon-motion` | Layered, staggered, depth movement |
| Numbers, titles, key phrases, steps, quotes | `agentoon-typography` | Kinetic/word-timed type |
| Hard topic change, location change, time jump, tool-to-tool jump | `agentoon-transitions` | Narrative cut types (max 2 families) |
| Any narrated video | `agentoon-robot`, `agentoon-audio`, `agentoon-qc` | Presenter, sound, gate |

## Typical combinations (examples, not templates)
- **MCP / API tutorial:** ui, diagrams, motion, robot, typography, audio, qc (+ transitions if more than five scenes).
- **3D architecture / product:** 3d, camera, motion, robot, transitions, audio, qc (typography for the disclaimer only).
- **Image transformations:** morph, ui (real tool captures), camera (push-ins on results), robot, typography, audio, qc.
- **GitHub / CLI tutorial:** ui, typography, motion, robot, audio, qc (+ diagrams only if architecture matters).
- **Hardware / device story (TV, phone):** ui (real docs/files), morph (project's before/after), diagrams (connection), robot, typography, audio, qc.

## Never
Stacking all twelve; adding 3D to a screen tutorial; a transition type used more than three times; a decorative animation presented as proof of a real connection; fake UI.
