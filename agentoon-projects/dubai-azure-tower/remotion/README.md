# Dubai Azure Tower - Remotion edit

1. Render scenes from Blender (see `../renders/RENDER_ON_PC.md`), then export each scene to `public/scenes/S01.mp4 ... S09.mp4` (`../exports/export_scenes.py`).
2. Copy `../audio/azure_score.wav` to `public/`.
3. `npm install` then `npm run studio` or `npm run render` -> `out/Dubai_Azure_Tower_4K.mp4`.

The composition is 3,600 frames @ 30 fps, 3840x2160, with scene fades, title card and concept disclaimer.
