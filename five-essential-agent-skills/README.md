# Five Essential agent skills

A single-file agent skill that coordinates five complementary Claude Code tools:

1. Find Skills
2. Superpowers
3. Claude Mem
4. Impeccable
5. Task Observer

## Download and upload

Download [Five Essential agent skills.md](./Five%20Essential%20agent%20skills.md), then upload it directly in **Claude Settings → Capabilities → Skills**. No ZIP is required.

The canonical agent-skill entrypoint is [SKILL.md](./SKILL.md). Both files contain the same validated definition with the safe internal identifier `five-essential-agent-skills`.

## Capabilities

- Discover and verify installable skills
- Apply structured planning, testing, review, and completion workflows
- Maintain approved cross-session project context
- Improve frontend design, accessibility, responsiveness, and visual polish
- Capture workflow lessons and propose skill improvements for human review

## Privacy

Never place credentials, patient information, employee records, or confidential client data in memory or observation logs. Confirm before enabling persistent services or hooks.
