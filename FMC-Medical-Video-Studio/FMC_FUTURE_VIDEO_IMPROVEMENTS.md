## 2. Changes actually implemented (source code changed)
**Audio policy (enforced, not just declared)**
- `src/lib/audioPolicy.tsx` — `FMC_AUDIO_POLICY` (exact flags you specified + `footageAudioEnabled:false`), `FMC_AUDIO_TARGETS`, `NarrationAudio`, `PolicySfx` (renders nothing unless flag **and** approval id), `footageMuted()`, `enforceRenderProps()`, `assertSfxAllowed()`.
- `MedicalExplainer.tsx`: removed the per-scene whoosh block, the music `<Audio>`, the music-volume helper, the red status banner and the progress hairline; narration via `NarrationAudio`. `DoctorExplainer.tsx`, `CharacterPreview.tsx`: narration via `NarrationAudio`. `TreatmentScene`: footage muted via policy.
- `scripts/render-video.ts`: `enforceRenderProps()` before every render; draft label no longer passed to the composition (no on-screen banner).
- `scripts/mix-audio.ts`: effects refused unless policy flag + `--sfx-approval`; default music now the soft pad bed at −34 LUFS (piano removed as default); runs `audio:qc` automatically after the mix and writes `<out>.audio-qc.md`; mux limiter fixes the AAC peak overshoot.
- `scripts/make-audio-bed.ts`: no longer generates a whoosh.
- Assets: `whoosh.mp3` and the piano track moved to `assets/audio/_retired/`; optional effects moved to `assets/audio/sfx-optional/` (unreferenced); `assets/audio/sfx/` no longer exists.
- **Tested:** (a) requesting an effect without approval aborts with the policy error; (b) a default mix completes and its QC passes; (c) a deliberately injected raw `<Audio>` + `sfx/whoosh.mp3` reference made `audio:qc` fail with 2 errors (probe file removed afterwards).

**Audio QC — `npm run audio:qc [-- --video f.mp4 --stems dir]`** (`scripts/audio-qc.ts`)
Static: every `<Audio>`/video element in `src/`, sfx-like identifiers, direct audio references, registered (nested) compositions, audio assets by category, footage files with embedded audio streams, policy flags, presence of the pipeline gates. File: integrated loudness, true peak, clipped samples, bright non-speech transients (≥14 dB rise) and whether they are near a scene seam, level around each seam, stem check for non-silent effects. It reports leads only — it does **not** claim to identify the source of a sound, and it cannot judge comfort.

**Standards QC — `npm run standards:qc [-- --video f.mp4]`** (`scripts/standards-qc.ts`) + `src/lib/fmcStandards.ts`
Clean-shaven (static identifier check) and official logo on coat; camera presets' real doctor % / visible height computed from geometry; card word counts and counts; font-size minimums; scene-variety rules (once `sceneType` is declared); logo file hash/alpha and no alternate logo assets; no status banner in the template; rendered file: 1080×1920/30 fps/h264/yuv420p/AAC/duration, red bottom banner, content touching side edges, bright content in the Instagram bottom zone. `npm run qc:all` runs Arabic check + both.
Run on V6 Clean it found: FAIL on one real item (13-word card in the FMC scene), warnings for small fonts, 4 cards in symptoms, an 8-word title, undeclared scene types, `yuvj420p`, bright content touching side edges at many sampled frames and bright content in the bottom zone at many sampled frames (`output/V6/standards_qc_V6.md`) — these are leads to inspect on frames, not verdicts.

**Character / camera**
- `src/components/Doctor/cameraPresets.ts`: presets moved out of the script into a reusable module with per-shot standards (full-body intro, medium speaking, anatomy explanation, pain demonstration, pointing to treatment, close-up, anatomy focus, closing); `BESIDE` pulled back (doctor 45 % → 43 %); `lowerBackScript.ts` imports it.
- `CHARACTER_SPEC` and `SCENE_TYPES` A–F encoded in `fmcStandards.ts`.

**Branding**
- `LogoMark` (variants `seal` for dark scenes, `bare` for light scenes) and `LogoBug` now renders the seal instead of the square white plate. The PNG is untouched (hash-pinned). Checked on a rendered still (`LogoStudy` composition → one PNG), not in a full video.

**Config / docs**
- `remotion.config.ts`: `yuv420p`. `docs/FMC_PRODUCTION_STANDARDS.md`, `CLAUDE.md` (standing rules for future sessions), npm scripts `audio:qc`, `standards:qc`, `qc:all`, `audio:pads`.
